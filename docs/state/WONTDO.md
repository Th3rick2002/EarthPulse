# Fuera de alcance por ahora

- Tendencias no lineales y eliminación de ciclos estacionales: quedan fuera del MVP descrito en el plan.
- Autenticación compleja: no se necesita para la demo inicial.
- Añadir fuentes o variables sin producto identificado, cobertura suficiente, unidad y método de transformación: evita resultados que no se puedan explicar o reproducir.
- Persistencia duradera de todos los datos crudos externos: requiere revisar licencias, coste y política de retención de cada dataset.
